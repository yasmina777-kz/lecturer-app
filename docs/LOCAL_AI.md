# Локальный AI-наставник — пилот

Открыть: http://localhost:5173/local-mentor. Ссылка есть на главной странице и в обзоре.

## Что реализовано

- Предобученная `Xenova/multilingual-e5-small`, ONNX q8, выполняется через Transformers.js 4 / WASM в отдельном Web Worker. Модель не обучалась командой AI Mentor.
- Модель вычисляет векторы вопроса и учебных фрагментов. По косинусному сходству выбирается исходный фрагмент. Новые тексты не генерируются, ответ сопровождается источником.
- Пилот на русском: шесть разделов по дробям и подготовленные проверочные вопросы. Проверка ответа и рекомендация повторить материал — обычная логика, не ML.
- Можно вставить свой текст или открыть локальный TXT/MD до 100 КБ. До 40 000 символов в поле, максимум 80 фрагментов. Для PPTX/PDF пока скопируйте текст. Тесты для пользовательских материалов не генерируются.
- В существующих лекциях кнопка «Задать вопрос» запускает тот же локальный поиск по доступным слайдам. Облачный `/api/questions/ask` больше не используется этим экраном. Историю новых ответов храним только в памяти страницы.
- Озвучка на этих экранах использует только системные SpeechSynthesis-голоса с `localService=true`. При отсутствии голоса остаётся текст. Ввод вопросов пока текстовый. Голос не переводит исходный материал.
- Сохранён текущий портрет наставницы с индикатором речи. Это не новая 3D-модель и не фонемная синхронизация губ.

## Запуск

```sh
cd frontend
npm ci
npm run prepare:local-ai
npm run dev
```

`npm run build` автоматически запускает подготовку модели. Вес модели и токенизатора примерно 135 МБ; вместе с WASM первая загрузка в браузер — порядка 170 МБ. Файлы берутся с того же сайта, удалённый inference отключён (`allowRemoteModels=false`). Для загрузки зависимостей/модели при сборке интернет нужен. Кэш браузера может быть очищен, поэтому полноценный офлайн-запуск всего сайта не гарантируется.

Страница `/local-mentor` доступна без входа и может отрисоваться даже при недоступном сервере аккаунтов. Существующие лекции, группы и прогресс по-прежнему используют обычный сервер платформы.

Кнопка отмены завершает worker, при выходе со страницы он освобождается. Материал индексируется в памяти worker, повторные вопросы используют готовый индекс. Материал и вопросы не отправляются в OpenAI/Azure/Hugging Face; модель загружается заранее при сборке сайта.

## Проверка качества

```sh
npm run test:local-ai
npm run build
```

`docs/local-ai-evaluation.json` содержит небольшую техническую проверку реальной ONNX-модели, не полноценную оценку качества. Порог 0.84 выбран консервативно для русского пилота. Сходство не является вероятностью правильности. Вопрос «Что больше: треть или пятая часть?» и англоязычный вопрос в проверке отвергаются как недостаточно надёжные; это известные ограничения, а не подтверждение поддержки этих запросов. Английские и казахские вопросы нужно отдельно оценивать. На других предметах порог также требует проверки; высокий балл не гарантирует правильного выбора.

## Что не изменено

Старые функции генерации лекций по теме, облачных отчётов и прочие внешние AI-интеграции не заменены этим пилотом. Они могут требовать серверный ключ. Ключи из .env не читались и не копировались в клиентский код. Новому режиму они не нужны.

## Как сделать собственное обучение

Следующий этап — подготовить согласованный с преподавателем датасет «вопрос → тема/тип ошибки → объяснение», разделить на обучающую и независимую тестовую выборки, обучить небольшой классификатор на признаках E5, измерить ошибки и экспортировать веса в браузер. Нельзя называть загрузку презентаций или текущий поиск обучением собственной модели. Требование AI Sana к самостоятельному обучению нужно подтвердить отдельно.

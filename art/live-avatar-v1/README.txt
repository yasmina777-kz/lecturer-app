AI Mentor — живой 3D-аватар

На главной странице: http://localhost:5173/#talking-avatars
Женский пример использует настоящую GLB-модель из Blender, WebGL и Web Audio.
В нём нет видеоролика: морф MouthOpen изменяется по текущему аудиосигналу.
Есть моргание, спокойные движения, жесты, поворот и полный рост.
На паузе рот закрывается. Записи можно менять прямо в браузере; файл остаётся локальным.
Точные фонемные формы губ пока не настроены. Это стилизованная базовая модель.
Произвольный текст голосом «ким» не синтезируется: по умолчанию звучит присланная запись.
Мужской видеопример не изменён. Лекционный плеер в кабинете этим демо не заменён.
На Vercel изменения не публиковались.

Исходники: frontend/src/components/LiveMentorAvatar.tsx и LectureAvatarDemo.tsx.
Модель: art/avatar-mentor-v1/AI-Mentor-Teacher-v1.blend.
Документация используемого загрузчика: https://threejs.org/docs/pages/GLTFLoader

Создано в Blender 4.5.9 LTS, 17 октября 2026.

ФАЙЛЫ
AI-Mentor-Teacher-v1.blend — редактируемая сцена Blender: персонаж,
скелет, материалы, анимации, студийное освещение и две камеры.
ai-mentor-teacher-v1.glb — персонаж со скелетом и анимациями для 3D-просмотра
и последующей интеграции в приложение. Студия в GLB не включена.
preview-full.png, preview-portrait.png, preview-back.png — рендеры модели.
preview-motion.gif — короткий предпросмотр жестов без звука.
build_avatar.py и export_glb.py — исходные скрипты создания и экспорта модели.
Для повторной сборки держите оба скрипта в одной папке.
model-report.json — характеристики, полученные из готовой сцены.

КАК ПОСМОТРЕТЬ
1. Откройте AI-Mentor-Teacher-v1.blend в Blender.
2. Пробел запускает спокойную анимацию Idle (кадры 1–120, 30 fps).
3. Для изменения позы выберите AI_Mentor_Rig и включите Pose Mode.
4. В редакторе NLA доступны дорожки Idle, Greeting и Explain.
   Для просмотра другого жеста выключите Idle и включите нужную дорожку.
   В Pose Mode можно сбросить предыдущую позу: выделить кости, Alt+R и Alt+G.
5. Морфы Blink и MouthOpen находятся в Object Data Properties → Shape Keys
   соответствующих частей лица. При ручном управлении отключите их NLA-дорожки.
6. F12 — рендер активной камеры. В сцене есть камеры полного роста и портрета.

ЧТО СДЕЛАНО
Стилизованный персонаж в полный рост: объёмные голова, глаза, нос, губы,
волосы, очки, серьги, жакет, топ, брюки, обувь, руки с отдельными пальцами.
Оригинальная процедурная геометрия и материалы без сторонних текстур.
Базовый FK-риг из 29 костей; все 106 частей модели привязаны к скелету.
Морфы: Blink (моргание), MouthOpen (открывание рта).
Клипы GLB: Idle, Greeting, Explain, Talk.

Talk — демонстрационное движение рта. Голоса и точной синхронизации
губ с фонемами в этом файле нет: их нужно подключать в приложении.
Это первая стилизованная модель с базовым ригом, без симуляции волос
и одежды. На действующем сайте аватар этим файлом не заменён.

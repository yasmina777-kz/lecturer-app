AI Mentor — женский видеопортрет с записью «ким»

Исходник: /Applications/ким, Ogg Opus, около 45,5 секунды.
kim-original.ogg — сохранённая исходная запись без изменений.
kim.wav — та же запись, декодированная в PCM для обработки.
female-kim-v2.mp4 — портрет с мимикой, рассчитанной под всю запись.

Это использование готового аудио, не клонирование голоса.
Мужской видеопример остаётся прежним.
Анимация создаётся SadTalker локально; это не Blender-модель.
Для снижения резких изменений применён центрированный фильтр Savitzky–Golay
на 5 кадров, порядок 2, только к коэффициентам выражения лица.
Голос не растягивается по времени, начало аудио не обрезается.
Улучшение чёткости — GFPGAN с фиксированным выравниванием лица
по первому кадру (эта запись рассчитана с неподвижной головой --still). Возможны артефакты синтетической мимики.

Окружение: ~/Documents/Codex/tools/SadTalker/.venv/bin/python
Модели и зависимости уже установлены на этом Mac.
Запуск: run_sadtalker.py --driven_audio kim.wav --source_image portrait.png
        --result_dir render --preprocess full --still --size 256 --batch_size 1 --verbose
После получения видео: enhance_video.py --input <rendered.mp4>
        --audio kim.wav --output female-kim-v2.mp4
Проверка: тем же Python выполнить finish_recording.py.

Проверенная страница: http://localhost:5173/#talking-avatars
Внешний сайт Vercel этой локальной работой не публикуется.

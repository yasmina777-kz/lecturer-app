AI MENTOR — 3D-РЕКОНСТРУКЦИЯ ЖЕНЩИНЫ ПО ПОРТРЕТУ, v1

Основной файл: AI-Mentor-Reference-Woman.blend
Открыть в Blender 4.5+, нажать пробел. На шкале 1366 кадров, 30 кадров/с.
В сцене сохранены запись «ким», мимика и плавные жесты на 45,49 секунды.
Звук упакован в .blend. Лицо содержит 51 FACS shape key; скелет — 29 костей.
Для просмотра других движений: NLA Editor, отключить Kim lecture gestures
и включить Idle, Greeting или Explain. Для ручного управления мимикой
отключить Kim facial speech на соответствующем блоке shape keys.

ЛИЦО И ДАННЫЕ
Лицо восстановлено локально KeenTools FaceBuilder 2026.3.1 по файлу
«ии модель ai модель.jpg», предоставленному пользователем.
Основной модуль установлен после разрешения пользователя на лицензию и
бесплатный пробный период. Проверка 17.10.2026: Trial mode active, 14 days left.
Платная подписка не приобреталась. SDK/веса KeenTools в проект не копировались.

ВОЛОСЫ, ТЕЛО, РЕЧЬ
Волосы — отдельная объёмная геометрия с прядями. Тело в одежде и скелет
взяты из собственного предыдущего Blender-исходника, прежняя голова удалена.
Для записи создано 295 звуковых интервалов Rhubarb Lip Sync 1.14.0
(phonetic recognizer). Они преобразованы в формы FACS с плавными переходами.
Мужской пример не менялся. Голос не клонировался: звучит исходная запись.

ПРОСМОТР НА САЙТЕ
http://localhost:5173/#talking-avatars → «Включить аватара».
reference-woman.glb: реальная 3D-геометрия, материалы, скелет, 51 форма лица,
анимации Idle, Greeting, Explain. Речь и пауза управляются из браузера,
а не видеороликом; для «ким» используются данные kim-visemes.json.
Для другой локальной аудиозаписи — только реакция на громкость, поскольку
отдельная звуковая разметка для неё ещё не создана.
Изменения локальные; Vercel в этой задаче не обновлялся.

ОГРАНИЧЕНИЯ
Это первая реконструкция, не готовый фотореалистичный цифровой двойник.
Единственная фотография не задаёт профиль, затылок, тело и скрытые поверхности.
Волосы, одежда и тело приблизительные. Точная артикуляция и сходство на всех
ракурсах требуют ручной доработки. Нет физической симуляции волос и одежды.
Анимация для Kim не предназначена для произвольного нового текста.

ВОСПРОИЗВЕДЕНИЕ СБОРКИ
reconstruct_face.py → build_reference_avatar.py → animate_recording.py → finalize_assets.py → finish_wardrobe.py
Первый шаг требует активного FaceBuilder. Сохранённые .blend и .glb
содержат геометрию и анимацию для обычного просмотра без запуска FaceBuilder.

# AI Mentor — интерактивные занятия с AI-преподавателем

React + TypeScript + ASP.NET Core 8 + Entity Framework Core. Интерактивные лекции, векторный AI-аватар, голосовые вопросы и практика на русском, английском и казахском.

## Быстрый запуск на Mac

Нужны .NET SDK 8, Node.js 20.19+ (или 22.12+) и Python 3.

1. Скопируйте `.env.example` в `.env` (`cp .env.example .env`), если `.env` ещё нет. Для демо ключи можно оставить пустыми. Откройте `start.command` двойным щелчком или выполните `python3 scripts/launch.py` в папке проекта.
2. Откройте http://localhost:5173 — сначала отображается главная страница с описанием проекта. Кабинет находится по `/dashboard`.
3. Все регистрируются как **студенты**. Администратор назначает роль **Lecturer** в разделе **Пользователи**; затем пользователь входит заново. Аватар, голос и язык выбираются в **Настройках**.
4. Для администратора отдельно запустите `create-admin.command`. Введите новый email, имя и пароль. Пароль не отображается в терминале.
5. Войдите с данными администратора: в меню появится **Админ-панель**.

Сервер работает на `localhost:5050`; frontend — на `localhost:5173`. Окно запуска должно оставаться открытым. Ctrl+C останавливает оба процесса. Скрипт не останавливает чужие процессы, занимающие эти порты.

## Подключение AI

Откройте `configure-ai.command`. Введите свой OpenAI API-ключ и модель (по умолчанию `gpt-4o-mini`). Затем перезапустите приложение.

Ключ сохраняется в `local.config.json` с правами `600`, исключён из Git и не передаётся в браузер. Альтернатива — переменные окружения:

- `OPENAI_API_KEY` или `AI__ApiKey` — ключ API.
- `AI__Model` — модель генерации и ответов, поддерживающая JSON mode Chat Completions.
- `AI__BaseUrl` — адрес API, по умолчанию `https://api.openai.com/v1/`.
- `AI__TranscriptionModel` — модель распознавания, по умолчанию `whisper-1`.

Локальный launcher читает `.env` и `local.config.json` автоматически. Приоритет: **окружение процесса → local.config.json → .env → настройки приложения**. Пустые поля `.env` пропускаются. После изменения настроек перезапустите приложение. Если старый ключ сохранён мастером в `local.config.json`, измените его через тот же мастер либо удалите соответствующую запись, прежде чем настраивать ключ в `.env`.

В `.env` используется формат `KEY=value`; пробелы и `#` внутри значения можно заключить в одинарные или двойные кавычки. Команды оболочки, подстановка `${VARIABLE}`, escape-последовательности и многострочные значения не выполняются. Поддерживаются только серверные настройки из шаблона; не используйте `VITE_` для секретов. При прямом `dotnet run` переменные нужно передать в окружении отдельно. Docker Compose читает `.env` своими средствами.

Без ключа работают аккаунты, готовая демонстрационная лекция, озвучка браузером, конспект, заметки, тесты, задания и админ-панель. Создание новой AI-лекции и ответы на вопросы требуют действующего ключа и доступа к выбранной модели. Интерфейс не выдаёт шаблонную лекцию за результат AI.

Использованы официальные контракты [Chat Completions / JSON mode](https://developers.openai.com/api/docs/guides/structured-outputs) и [Audio Transcriptions](https://developers.openai.com/api/reference/resources/audio/subresources/transcriptions/methods/create).

## Что реализовано

- Регистрация, вход, выход, сессии в HttpOnly cookie, профиль. Форма «Безопасность» временно убрана; серверная защита и локальное восстановление пароля сохранены.
- Роли Student, Lecturer, Admin; регистрация всегда создаёт Student, даже если запрос содержит другую роль. Администратор создаётся только локальной командой или назначается действующим администратором.
- Обзор, поиск и фильтры библиотеки, личные и опубликованные лекции.
- Создание лекции из темы или PDF, DOCX, PPTX, TXT, MD. Выбор 5, 10, 15, 20 или 30 минут (3, 5, 8, 10, 15 слайдов). Генерация подробного рассказа и векторной инфографики частями по 3 слайда.
- Вступление с выбранным векторным аватаром → слайды с голосом → пауза на вопрос → ответ с аватаром → продолжение с текущего предложения.
- Текстовые и голосовые вопросы, история вопросов, остановка микрофона, ограничение записи 60 сек.
- Переключение слайдов, пауза и продолжение, скорость речи, сохранение прогресса.
- Конспект и скачивание TXT; личные заметки; тесты с проверкой на сервере; сохранение практических ответов и примеры для самопроверки.
- Название и удаление собственной лекции; преподаватель публикует собственные лекции, администратор — любые.
- Админ-панель: статистика, пользователи, роли, блокировка, публикация и удаление лекций, вопросы, сервисы и **Расход AI**. Токены учитываются по операции, пользователю и лекции, с фильтром периода и журналом.
- Интерфейс на русском, английском и казахском; язык сохраняется в профиле и на устройстве.
- Каталог: мужской и женский векторные персонажи. 3D-аватар временно отключён; прежние записи с UEAvatar отображаются векторным персонажем согласно выбранному полу голоса.
- Язык лекции, аватар, оформление и пол голоса сохраняются в самой лекции при создании. Студенты видят настройки автора. Изменение профиля не меняет уже созданные лекции.
- Демонстрационные лекции с конспектом, тестом и заданиями на трёх языках. Пользовательские материалы автоматически при переключении меню не переводятся.
- Главная с подробным описанием, интерактивными этапами занятия, вкладками для студентов и преподавателей, FAQ.
- Две сгенерированные иллюстрации в `frontend/public/images/`, последовательное появление карточек, плавающие элементы и кнопка остановки анимации; новые тексты переведены на RU/EN/KZ.
- Графитовая главная со стальными акцентами, светлый учебный кабинет; палитра #21262B / #A9A9A9 / #F1F1F1 / #778899, анимации и поддержка prefers-reduced-motion.
- Кнопки RU / EN / KZ в шапке и подвале; дата и подпись «Личное пространство» убраны.
- Адаптивный интерфейс, состояния загрузки и понятные ошибки.
- Локальное восстановление пароля: `reset-password.command`. Оно требует доступа к компьютеру с сервером и завершает прежние сессии пользователя. Email-рассылка не подключена.

## Голос на трёх языках

Откройте `configure-speech.command`, введите **ключ Azure Speech** и **регион именно этого ресурса**, затем перезапустите приложение. Секрет остаётся в `local.config.json` на сервере. Для Docker или прямого запуска используйте `AZURE_SPEECH_KEY` и `AZURE_SPEECH_REGION`.

| Язык | Мужской голос | Женский голос |
|---|---|---|
| Русский | Dmitry | Svetlana |
| English | Guy | Jenny |
| Қазақша | Daulet | Aigul |

Текст озвучки передаётся Azure Speech, сервер возвращает MP3. Без ключа используются голоса устройства, соответствующие языку лекции. Браузер не гарантирует наличие казахского голоса или точный пол системного голоса: при отсутствии подходящего голоса приложение сообщает об этом. Русский голос вместо казахского не подставляется. Голос можно прослушать после входа в настройках.

Ключ Azure не нужен для выбора и сохранения аватара, голоса или языка. Ключ генерации AI и ключ Azure Speech — отдельные настройки. Наличие ключа в админ-панели означает, что он введён, а не что доступ к облачному сервису уже проверен.

Документация: [голоса Azure Speech](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/language-support?tabs=tts), [REST text-to-speech](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/rest-text-to-speech).

## Данные и ограничения

SQLite создаётся автоматически в `backend/src/Lecturer.Api/App_Data/lecturer.db`; рядом хранится случайный ключ подписи сессий. Резервируйте папку целиком при остановленном сервере. Не публикуйте `App_Data` и `local.config.json`. Новая локальная база не изменяет вашу прежнюю PostgreSQL.

SQLite создаётся через `EnsureCreated`; существующая база получает поля языка, аватара, длительности и таблицу учёта AI через идемпотентный `SqliteSchemaUpgrade`. Обновление не удаляет аккаунты и материалы. Для PostgreSQL предусмотрены EF migrations, включая `TeacherAvatarsAndLanguages` и `LectureDurationAndAiUsage`.

PDF должен содержать текстовый слой: OCR сканов не включён. Ограничения: 10 МБ, 100 страниц PDF, 60 000 извлечённых символов. Из DOCX/PPTX извлекается текст, исходная вёрстка и изображения не переносятся. Оригинал загруженного файла не сохраняется; текст передаётся AI-провайдеру.

Аватары используют SVG-анимацию; Three.js и загрузка GLB удалены из активной версии. Движения рта приблизительные, без точной фонемной синхронизации. Голосовые вопросы требуют HTTPS или localhost и разрешения микрофона. При ошибках озвучки доступен текст и ручное переключение.

Тесты и задания предназначены для самопроверки, не для аттестации: правильные ответы и примеры входят в материалы лекции. Администратору доступны лекции и вопросы пользователей. Учебные ответы AI следует сверять с источником.

## PostgreSQL

Задайте `Database__Provider=Postgres` и `ConnectionStrings__Default`. При запуске применяются существующие и новые EF Core migrations. Пример строки: `Host=localhost;Port=5432;Database=lecturer;Username=lecturer;Password=...`.

Сделайте резервную копию действующей базы до первого запуска новой версии. Старые лекции без владельца после миграции доступны администратору; он может опубликовать их. Старые лекции без слайдов показывают сообщение об отсутствии материала. Для старых лекций задания автоматически не генерируются — создайте новую из исходного материала.

## Docker

Docker-файлы и Compose добавлены, но запуск Docker в этой среде не проверялся: Docker Engine не запущен.

Создайте `.env` с `POSTGRES_PASSWORD` (собственный пароль), при необходимости `OPENAI_API_KEY`, затем:

```sh
docker compose up --build -d
docker compose exec backend dotnet Lecturer.Api.dll --create-admin
```

Откройте http://localhost:5173. База и ключи находятся в отдельных Docker volumes. Это локальная конфигурация: для публичного размещения дополнительно настройте домен, HTTPS, разрешённые origins, доверенный reverse proxy и резервное копирование. Публичное размещение не выполнялось.

## Разработка и проверки

```sh
dotnet build backend/src/Lecturer.Api
npm --prefix frontend ci
npm --prefix frontend run build
npm --prefix frontend test
dotnet run --project tests/SpeechChecks
python3 -m unittest discover -s tests -p 'test_settings.py'
```

Для тестов нужен Google Chrome. Playwright автоматически запускает отдельную временную SQLite и локальный тестовый AI-провайдер. Порты 5050, 5099 и 5173 должны быть свободны. Тестовые пользователи не записываются в рабочую базу.

Проверяются регистрация и роли, cookie-сессии, защита чужих лекций, генерация, импорт PDF/DOCX/PPTX/TXT, ответы и голосовой HTTP-контракт, прогресс/заметки/задания/тесты, блокировка, смена пароля, отзыв сессий, браузерный цикл вопроса с возобновлением и мобильная вёрстка.

Одиннадцать Playwright-сценариев включают главную страницу, регистрацию только студентом и назначение преподавателя администратором, три языка интерфейса, интерактивные вкладки и FAQ, сохранение настроек, только векторные аватары, длительность и инфографику, расход и кешированные токены, журнал ошибок, сохранение истории после удаления лекции, мобильную вёрстку. `SpeechChecks` проверяет шесть облачных голосов, SSML-экранирование, адрес/заголовки запроса и обработку ошибок на mock-транспорте. С аргументом пути к старой SQLite тест сначала создаёт временную копию и проверяет сохранность данных после двух обновлений схемы.

Реальный платный AI, распознавание настоящего голоса и облачные голоса без предоставленных ключей не проверялись. В browser-тесте события синтеза речи детерминированы; это проверяет переходы проигрывателя, но не качество голоса ОС.

Для PostgreSQL migrations:

```sh
dotnet tool restore
dotnet tool run dotnet-ef migrations add Name --project backend/src/Lecturer.Infrastructure --startup-project backend/src/Lecturer.Api
```

Ключевые папки: `frontend/src/pages` — экраны; `frontend/src/hooks` — речь, запись, загрузки; `backend/src/Lecturer.Api/Controllers` — API; `backend/src/Lecturer.Api/Services` — AI, импорт, сессии, демо; `backend/src/Lecturer.Infrastructure/Migrations` — PostgreSQL; `tests` и `frontend/tests` — проверки.

## Длительность, иллюстрации и стоимость AI

Длительность — цель при темпе примерно 110 слов/мин, без вопросов, пауз и самостоятельной практики. На странице готовой лекции отображается оценка по фактическому тексту; скорость воспроизведения меняет время. Сначала создаётся план/конспект/задания, затем подробное объяснение партиями по 3 слайда. Слишком короткий, длинный или некорректный ответ отклоняется; оплаченные токены такого ответа остаются в журнале. Автоматических повторов платных запросов нет.

Иллюстрации сейчас — векторная учебная инфографика: процессы, сравнения и понятия с иконками, связями и подписями. AI возвращает строго структурированные данные; HTML/SVG-код и внешние URL модели не исполняются. Фотографии и отдельная растровая генерация не подключены. Старые лекции сохраняют прежнее содержимое.

Расход начинается с момента обновления. Сохраняются только метаданные: пользователь, ID лекции, операция, модель, статус, input/cached/output tokens и вычисленная стоимость. Тексты материалов и ключи в журнал не пишутся. История остаётся после удаления лекции; неуспешная генерация имеет ID, даже если готовая лекция не сохранена. Нет usage в ответе — значения неизвестны (null), а не нулевые. Незавершённый при аварийном выключении запрос остаётся pending; его результат нужно сверять с провайдером.

Стандартный тариф OpenAI GPT-4o mini, проверен 2026-09-25: $0.15 за 1 млн входных, $0.075 за кешированные входные, $0.60 за выходные токены. Кеш входит во входные токены и не суммируется с ними повторно. Формула: ((input − cached) × 0.15 + cached × 0.075 + output × 0.60) / 1 000 000. Это расчётная стоимость, не платёжный документ; налоги, кредиты и индивидуальные договоры не учитываются.

Источник: https://developers.openai.com/api/docs/models/gpt-4o-mini
Usage API: https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create

Неизвестная модель или сторонний AI:BaseUrl не получает автоматически тариф OpenAI. Для другой модели/провайдера можно задать AI__InputUsdPerMillion, AI__CachedUsdPerMillion, AI__OutputUsdPerMillion; без тарифа стоимость остаётся неизвестной. Смена тарифа не переписывает ранее сохранённую стоимость. Azure Speech и браузерная озвучка в текстовые токены не входят. Распознавание Whisper записывает длительность аудио; его стоимость в USD не вычисляется.

Предварительная оценка для русской темы без файла: 10 минут ≈ $0.0031–0.0057; 20 минут ≈ $0.0056–0.0102; 30 минут ≈ $0.0079–0.0145. Это эвристика для текущего многошагового алгоритма, не измерение реальных генераций. Материал до 60 000 символов повторно передаётся при генерации частей и увеличивает входные токены. Для 20 минут и 60 000 символов ориентир ≈ $0.018–0.037. Вопросы, повторы, распознавание, облачная озвучка, фотографии и сервер оплачиваются отдельно. Счётчик показывает фактические токены после ответа.

## Структура репозитория

```text
frontend/       React/TypeScript: главная, кабинет, лекции, админка
backend/src/    ASP.NET Core API, модели, база и миграции
scripts/        Локальный запуск и чтение конфигурации
tests/          Тестовый AI-провайдер, импорт, голос и настройки
.env.example    Шаблон переменных окружения
.gitignore      Исключения для Git
docker-compose.yml  Локальный PostgreSQL + backend + frontend
```

Публикуйте исходники, lock-файл npm, миграции, README и `.env.example`. `.gitignore` исключает `.env`, `local.config.json`, `App_Data`, ключи, локальные базы, node_modules, bin/obj, dist, логи и отчёты тестов. Он не удаляет файлы с диска и не убирает уже закоммиченные секреты из истории.

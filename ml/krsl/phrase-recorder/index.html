Локальная запись фраз для учебного исследования

Это не часть публичной платформы. Видео остаются в этом браузере до скачивания; страница не загружает их на сервер. Записи нельзя использовать для обучения, пока РЖЯ-компетентный рецензент не проверит значение и разметку.

Один и тот же участник должен записываться только в одной группе. Иначе тест покажет завышенное качество.

Записывайте только естественное выражение смысла. Не просите дословно переводить русскую фразу жест за жестом. Каждая запись перед использованием должна пройти независимую проверку носителем или преподавателем РЖЯ.
